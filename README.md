# Green Garden

Este é o catálogo digital da flora presente na Universidade de Fortaleza (UNIFOR). O projeto utiliza Next.js e Tailwind CSS para oferecer uma experiência interativa e educativa.

## 🚀 Começando

Para rodar o projeto localmente:

```bash
cd frontend/my-app ->
npm run dev
# ou
yarn dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

## 🌿 Funcionalidades

- **Catálogo Completo**: Mais de 37 espécies catalogadas com fotos, nomes científicos e importância ecológica.
- **Navegação por Blocos**: Mapa interativo para localizar plantas em setores específicos do campus.
- **Design Moderno**: Interface premium desenvolvida com `shadcn/ui`.
- **SideMenu Integrado**: Navegação rápida acessível de qualquer lugar da aplicação.

## 🛠️ Tecnologias

- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide React Icons](https://lucide.dev/)
- [shadcn/ui](https://ui.shadcn.com/)
